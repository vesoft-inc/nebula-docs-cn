# 数据同步

{{dashboard_ent.name}}的**数据同步**功能用于在集群间实现数据同步。

## 注意事项

- 只有 3.1.3 及以上的企业版集群支持数据同步。
- 集群的版本必须相同，以便在彼此之间同步数据。
- 暂不支持切换主从集群。

!!! note

    关于数据同步功能的更多注意事项和详细信息，请参见[集群间数据同步](../../synchronization-and-migration/replication-between-clusters.md)。

## 入口

单击{{dashboard_ent.name}}顶部导航栏的**集群管理**，在目标集群右侧单击**详情**，再点击左侧导航栏的**数据同步**。

## 准备工作

### 主集群准备工作

1. 在页面上方单击**服务配置**。
2. 勾选包含 Meta 服务的节点，单击**添加 Meta Listener**。
3. 勾选包含 Storage 服务的节点，单击**添加 Storage Listener**。
   
  <img src="https://docs-cdn.nebula-graph.com.cn/figures/ec_dash_synchronization_master_240108_cn.png" width="600" alt="service configuration for the master cluster">

4. 单击**确定**，确认所有依赖服务的信息。

### 从集群准备工作

1. 在页面上方单击**服务配置**。
2. 勾选所有节点，单击**添加 Drainer**。

  <img src="https://docs-cdn.nebula-graph.com.cn/figures/ec_dash_synchronization_slave_240108_cn.png" width="600" alt="service configuration for the slave cluster">

3. 单击**确定**，确认所有依赖服务的信息。

## 创建数据同步任务

1. 在页面上方单击**新建同步**。
2. 勾选主集群中需要同步数据的图空间。右侧的名称是从集群中待同步的图空间名称，该名称可以修改。修改完成后单击**下一步**。

  <img src="https://docs-cdn.nebula-graph.com.cn/figures/ec_dash_synchronization2_240108_cn.png" width="300" alt="set the synchronization graph space">

3. 在下拉框中选择数据同步的从集群，单击**下一步**。
4. 单击**开始同步**。
5. 确认数据同步任务的创建结果。

  <img src="https://docs-cdn.nebula-graph.com.cn/figures/ec_dash_synchronization3_240108_cn.png" width="300" alt="set the synchronization graph space">

## 其他操作

数据同步页面可以查看同步信息，以及停止或取消同步。

- 查看同步信息：数据同步页面会展示本集群内的同步图空间名称、关联的从集群、从集群中的同步图空间名称、同步状态等。
- 停止/开始同步：暂停/重启数据同步。
- 取消同步：删除数据同步任务。
