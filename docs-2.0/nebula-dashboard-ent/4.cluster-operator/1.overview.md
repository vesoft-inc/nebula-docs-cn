# 集群总览

本文主要介绍 Dashboard 的集群总览页面。

## 入口

1. 在 NebulaGraph Dashboard 企业版顶部导航栏，单击**集群管理**。
2. 在目标集群右侧**详情**，即可进入指定集群的集群总览页面。

## 概览

Dashboard 的集群总览页面分为以下几个部分：

- 集群关键信息
- 集群拓扑
- 节点监控
- 服务监控

### 集群关键信息

在集群关键信息中，展示如下信息：

- 集群健康分：按百分制展示集群的健康程度。每 5 分钟刷新一次，若出现 emergency 级别的告警则立刻刷新。计算公式可以在**集群诊断**页面进行配置。
- 监控中的节点：展示在线节点数/总节点数。
- 监控中的服务：展示在线服务数/总服务数。不同类型的服务分别展示。
- 集群信息：展示集群名称、创建时间、创建用户、版本、所有者以及版本升级入口。
- 存在时间：集群运行总时长。
- 服务在线时长比例：集群状态为可用的时长比例。计算公式可以在**集群诊断**页面进行配置。
- 慢查询：集群中的慢查询数量。
- 最大 QPS：集群中的最大 QPS。
- 最大查询延迟：集群中的最大查询延迟。
- 打开 session 数量：集群中创建过的会话总数。
- QPS：QPS 时序图。
- Query Latency：Query Latency 时序图。

### 集群拓扑

展示集群中的节点和服务分布及状态。

### 节点监控

- 支持快速查看节点监控信息，支持添加或删除监控指标。
- 支持在页面上单击![setup](https://docs-cdn.nebula-graph.com.cn/figures/Setup_cn.png) 插入基准线。
- 单击![watch](https://docs-cdn.nebula-graph.com.cn/figures/watch_cn.png) 快速跳转至节点监控页面，查看详情信息。

### 服务监控

- 支持快速查看服务监控信息，支持添加或删除监控指标。
- 支持在页面上单击![setup](https://docs-cdn.nebula-graph.com.cn/figures/Setup_cn.png) 插入基准线。
- 单击![watch](https://docs-cdn.nebula-graph.com.cn/figures/watch_cn.png) 快速跳转至节点监控页面，查看详情信息。
