# 集群诊断

集群诊断是在指定的时间范围内，定位及分析当前集群出现的问题，生成网页版的诊断报告。用户通过诊断报告可以排查出当前集群出现的问题，并可以对问题进行解决。


## 入口

1. 在 Dashboard 顶部导航栏，单击**集群管理**。
2. 单击目标集群右侧**详情**。
3. 在左侧导航栏，单击**集群信息**->**集群诊断**。


## 创建诊断

![diagnosepage](https://docs-cdn.nebula-graph.com.cn/figures/cluster-diagnose_2022-04-11_cn.png)

1. 选择诊断的时间范围。支持通过时间区间设置集群诊断的时间范围，包括：`1 小时`、`6 小时`、`12 小时``1 天`、`3 天`、`7 天`、`14 天`。

  !!! caution

        集群诊断是对集群历史数据的诊断，因此用户设置的诊断范围的结束时间不能超过当前时间。

2. 在**集群诊断**页面，单击**开始诊断**。

## 查看诊断报告

在诊断列表中，单击目标诊断右侧的**详情**。

集群诊断报告中包含以下内容：

- 诊断结果
- 基本信息
- 节点负载
- 流量 Network
- Session 信息
- 服务信息
- 配置信息

### 诊断结果

- 当集群中以下参数出现异常时，诊断结果中会显示相应的信息，包括参数名、类型、严重程度、详情。

  | 参数                               | 说明 |
  | ---------------------------------- | ---- |
  | `num_queries_hit_memory_watermark` |  用于统计执行的 nGQL 语句中达到内存水位值的数量。   |
  | `graphd_down  `                    |  表示 Graph 服务停止。   |
  | `storaged_down`                    |  表示 Storage 服务停止。    |
  | `metad_down`                       |  表示 Meta 服务停止。    |
  | `node-exporter down`               |  表示用于收集机器系统数据的服务停止。 |

- 当未诊断到集群中有任何异常时，诊断结果不显示任何信息。


### 基本信息

- **诊断区间**：显示生成报告的时间范围，包括开始时间和结束时间。

- **节点信息**：显示集群中节点的数量、CPU、内存、磁盘等信息。

  | 参数                               | 说明 |
  | ---------------------------------- | ---- |
  | `HOST` | 服务器的 IP 地址。   |
  | `INSTANCE`                    |  该服务器部署的实例数量，例如：`metad*1 graphd*1 storaged*1`。   |
  | `CPU`                    |  CPU 核数，单位 Core。    |
  | `MEMORY`                      |  表示服务器的内存大小，单位是 GB。    |
  | `DISK`               |  表示服务器磁盘大小，单位是 GB。 |


- **服务信息**：显示 Nebula Graph 各个服务的类型、所在机器 IP、服务端口、HTTP 端口、运行状态。

- **Leader 分布**：显示集群中 Leader 分布情况。
