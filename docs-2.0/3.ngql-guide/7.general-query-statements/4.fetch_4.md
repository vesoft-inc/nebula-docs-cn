# FETCH

## 获取点的属性值

### 语法

### 语法

```ngql
FETCH PROP ON {<tag_name>[, tag_name ...] | *}
<vid> [, vid ...]
YIELD [DISTINCT] <return_list> [AS <alias>];
```

|参数|说明|
|:---|:---|
|`tag_name`|Tag 名称。|
|`*`|表示当前图空间中的所有 Tag。|
|`vid`|点 ID。|
|`YIELD`|定义需要返回的输出。详情请参见 [`YIELD`](../8.clauses-and-options/yield.md)。|
|`AS`| 设置别名。|
