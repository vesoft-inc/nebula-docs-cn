## 获取点的属性值

### 基于 Tag 获取点的属性值

### 基于 Tag 获取点的属性值

在`FETCH`语句中指定 Tag 获取对应点的属性值。

```ngql
nebula> FETCH PROP ON player "player100" YIELD properties(vertex);
+-------------------------------+
| properties(VERTEX)            |
+-------------------------------+
| {age: 42, name: "Tim Duncan"} |
+-------------------------------+
```
