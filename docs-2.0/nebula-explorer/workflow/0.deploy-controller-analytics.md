# 部署 Nebula Analytics 和 Dag Controller

工作流需要 Nebula Analytics 和 Dag Controller 这两种服务才能正常运行，Nebula Analytics 用于进行图计算，Dag Controller 用于对任务进行编排调度。本文介绍如何部署这两种服务。

## 前提条件

- 已部署 2.2.x 或以上版本的[HDFS](https://hadoop.apache.org/docs/stable/hadoop-project-dist/hadoop-common/ClusterSetup.html)。

- 已安装 1.8 或以上版本的 JDK。

## 安装环境

不同的环境安装包和命令略有区别，本文的示例安装环境如下：

- 操作系统为 CentOS 7。
- 如果 Nebula Analytics 和 Dag Controller 分别部署在多台机器，请确保机器网络互通。
- 如果 Nebula Analytics 是分布式架构，请确保路径、端口等配置相同。

## 部署 Nebula Analytics

1. 安装 libatomic。

  ```
  sudo yum -y install libatomic
  ```

2. 安装 Nebula Analytics。

  ```
  sudo rpm -ivh <analytics_package_name> --prefix <install_path>
  ```

  例如：

  ```
  sudo rpm -ivh nebula-analytics-3.2.0-centos.x86_64.rpm --prefix=/home/vesoft/nebula-analytics
  ```

3. 配置`set_env.sh`文件，路径为`nebula-analytics/scripts/set_env.sh`。配置正确的 Hadoop 路径和 JDK 路径。如果有多台机器，请确保路径一致。

  ```
  export HADOOP_HOME=<hadoop_path>
  export JAVA_HOME=<java_path>
  ```

## 部署 Dag Controller

1. 配置 Dag Controller 机器与 Nebula Analytics 机器 SSH 免密登录。

  例如机器 A（Dag Controller）通过 SSH 远程登录至机器 B（Nebula Analytics），在机器 A 上执行如下命令：

  ```
  //执行后按提示生成密钥，默认按回车即可。
  ssh-keygen -t rsa

  //将机器 A 的公钥文件安装到机器 B 对应的用户下，即可从机器 A 免密登录机器 B。
  ssh-copy-id -i ~/.ssh/id_rsa.pub <B_user>@<B_IP>
  ```

2. 配置 SSH Agent 代理，提高访问速度。

  ```
  eval $(ssh-agent)
  
  ssh-add ~/.ssh/id_rsa
  
  source ~/.bash_profile
  ```

3. 安装 Dag Controller。

  ```
  sudo rpm -ivh <analytics_package_name> --prefix <install_path>
  sudo chown <user>:<user> -R <install path>
  ```

  例如：

  ```
  sudo rpm -ivh dag-ctrl-1.0.0-centos.x86_64.rpm --prefix=/home/vesoft/dag-ctrl
  sudo chown vesoft:vesoft -R /home/vesoft/dag-ctrl
  ```

4. 配置`dag-ctrl-api.yaml`文件，路径为`dag-ctrl/etc/dag-ctrl-api.yaml`。配置 Nebula Analytics 机器的用户名及端口，如果有多台机器，请确保使用相同用户名。

  ```
  # Nebula Analytics 机器的用户名以及 SSH 端口。
  SSH:
    UserName: vesoft
    Port: 22

  #任务和作业的并行线程池大小。
  JobPool:
    Sleep: 3    # 3 秒检查一次有没有未执行的作业。
    Size: 3    # 同时可以执行 3 个作业。
  TaskPool:
    CheckStatusSleep: 1    # 1 秒检查一次任务状态。
    Size: 10    #同时可以执行 10 个任务。

  Dag:
    VarDataListMaxSize: 100    # 如果读取 HDFS 的列，则限制为每次 100 条数据。
  ```

5. 配置`plato_tasks.yaml`文件，路径为`dag-ctrl/etc/plato_tasks.yaml`。配置算法文件的具体路径，如果有多台机器，请确保路径一致。主要修改`exec_file`参数的值，可以用如下命令批量替换。

  ```
  sudo sed -i "s/caton.hao/vesoft/g" `grep -rl caton.hao`
  ```

6. 启动 Dag Controller。

  ```
  cd <dag_ctrl_install_path>
  ./scripts/start.sh
  ```
  
7. 确认是否启动成功。

  ```
  netstat -aon | grep 9002
  ```
