# 什么是 NebulaGraph Data Science

NebulaGraph Data Science （简称 GDS）是一款数据挖掘工具，由 Jupyter Notebook、NebulaGraph、Spark、Algorithm 等产品组成，方便数据科学家们深度挖掘数据、革新数据模型、解决业务难题。

## 优点

- 所有产品组件均为开源，方便修改定制。
- 安装方便，集成所有产品组件，支持容器化安装。
- 使用简单，通过 Web 页面交互式开发及处理数据，方便配置工作流程。
- 可以整合大数据工具，例如 Apache Spark。
- Notebooks 文件便于分享。
- 发展潜力大，可以支持多种编程语言、接入各种组件，拓展功能。
