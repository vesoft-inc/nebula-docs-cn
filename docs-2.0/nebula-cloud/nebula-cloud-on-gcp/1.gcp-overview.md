# NebulaGraph Cloud GCP 版概览

NebulaGraph 提供了基于谷歌云平台（Google Cloud Platform，简称GCP）的安全、可靠的云服务。用户可以使用 Deployment Manager 模板快速部署一整套企业版 NebulaGraph 云服务，包含相应的网络、计算、存储、可视化等服务。

## 费用

谷歌云 Deployment Manager 不收取使用费，但使用 Deployment Manager 部署的资源可能产生费用。例如，Compute Engine 按照 [Compute Engine 价格表]((https://cloud.google.com/compute/pricing))收取资源费用。 如需了解详情，参阅各产品对应的价格表。

部署 NebulaGraph 服务集群后，用户可以通过[结算报告](https://cloud.google.com/billing/docs/how-to/reports#overview)查看费用与消费趋势。

此外，用户需要为 NebulaGraph 服务申请许可证，并保持许可证有效。申请许可证需要一定的费用。

## 许可证

NebulaGraph Cloud GCP 版使用 NebulaGraph 企业版服务，默认提供有效期 3 天的试用版许可证。许可证到期后服务不可用，数据依然保留在 GCP 资源中。

申请和设置许可证的说明参见[设置内核许可证](../../4.deployment-and-installation/deploy-license.md)<!--、[设置 Dashboard 许可证](../../nebula-dashboard-ent/11.dashboard-ent-license.md)-->和[设置 Explorer 许可证](../../nebula-explorer/deploy-connect/3.explorer-license.md)。
