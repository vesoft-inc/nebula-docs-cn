# 部署架构

使用 Deployment Manager 模板创建 NebulaGraph 服务集群时可以按需调节集群组件。本文介绍生产环境中推荐的部署架构。

生产环境中典型的集群架构如下图所示。

![GCP 部署架构](https://docs-cdn.nebula-graph.com.cn/figures/gcp-architecture_2022.09.01.png)

以上架构中包含：

- 一个用于部署 NebulaGraph 集群的 VPC。
- 分别由 metad、graphd、storaged 支持的 NebulaGraph Meta 服务、Graph 服务和 Storage 服务。每个进程运行在一台谷歌云虚拟机实例中。
- 一台 NebulaGraph Explorer 服务器，用于支持可视化图探索。
- 一台 NebulaGraph Dashboard 服务器，用于监控和管理 NebulaGraph 服务。
