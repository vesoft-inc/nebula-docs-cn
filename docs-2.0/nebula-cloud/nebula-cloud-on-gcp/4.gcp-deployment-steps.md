# 部署步骤

完成部署准备后即可开始部署 NebulaGraph 服务集群。

## 前提条件

已阅读本文档目录下的前置文档，并根据说明完成了部署准备。

## 操作步骤

1. 在[谷歌云控制台](https://console.cloud.google.com/flows/enableapi?apiid=deploymentmanager,compute_component&_ga=2.168093153.1320456914.1661838962-704336122.1649316074&_gac=1.117124468.1661841350.CjwKCAjwx7GYBhB7EiwA0d8oe1BnSsVFHk3AFov1HWrFGX4ZqXZfHXVLk3LwdY_yyxWWYElEA5m8yxoCN8EQAvD_BwE)，根据页面提示启用 Deployment Manager 和 Compute Engine 的 API。

2. 在工作站中，[安装谷歌云 Cli](https://cloud.google.com/sdk/docs/quickstarts)。

3. 运行以下命令指定部署要用的项目。

  ```bash
  gcloud config set project <myProjectId> # 将 <myProjectId> 替换成要使用的项目 ID.
  ```

4. 在 NebulaGraph 下载页，下载部署模板到工作目录中。

5. 根据需要修改模板中的参数，并用药使用的项目 ID 替换模板中的`<myProjectId>`。

6. 运行以下命令部署 NebulaGraph。

  ```bash
  gcloud deployment-manager deployments create nebula --config template/config_template.yaml
  ```
