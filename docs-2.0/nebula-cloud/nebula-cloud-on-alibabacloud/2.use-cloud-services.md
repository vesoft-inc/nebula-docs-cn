# 使用服务实例

创建好服务实例后，即可查看服务信息，并开始使用悦数图数据库服务。

## 查看服务实例

在计算巢控制台可以查看服务实例的详细信息，详情参见[查看服务实例](https://help.aliyun.com/document_detail/290838.html)。

## 查看连接信息

连接服务前，需要在阿里云计算巢的实例详情中查看各服务的连接地址。查看方式如下：

1. 登录[服务实例管理](http://c.nxw.so/9huj4 "https://computenest.console.aliyun.com/user/cn-hangzhou/serviceInstance/private")页面。

  !!! note

        如果要寻找的是免费试用版服务实例，需先在**服务实例管理**页面单击**试用服务**标签。

2. 在实例列表中，单击目标实例的**服务实例ID**，或其右侧**操作**列的**详情**。

3. 在**概览**标签页的**基本信息**区域，可以查看 Graph 服务、Storage 服务，以及 Explorer、Dashboard 等周边工具的连接信息。

## 连接悦数图数据库

悦数图数据库（阿里云版）提供多种连接方式。

### 使用客户端直连悦数图数据库

获取到连接地址后，即可使用悦数图数据库的各类客户端连接服务。

连接方式：

直连 Graph 服务的私网或公网 IP 地址。详细连接方式参见[客户端文档](https://docs.nebula-graph.com.cn/{{nebula.release}}/14.client/1.nebula-client/)。

如需通过公网连接悦数图数据库数据库：

1. 到 Graph 服务部署的 ECS 实例详情中找到其公网 IP 地址。

2. （仅付费版需执行该步骤）在悦数图数据库服务实例加入的安全组中，[添加安全组规则](https://help.aliyun.com/document_detail/25471.html)，允许从指定的公网 IP 地址访问 TCP 9669 端口。

  !!! note

        免费试用版默认允许从公网访问 Graph 服务的 9669 端口。

3. 使用 Graph 服务的公网 IP 地址和 9669 端口访问悦数图数据库数据库。

!!! caution

    建议仅通过私网 IP 连接，提高网络和数据的安全性。

### 使用 Explorer 连接悦数图数据库

使用图探索工具可以快速连接悦数图数据库，与图数据进行可视化交互。

连接方式：

1. 在浏览器中使用 **悦数图探索服务访问地址**打开悦数图探索。
2. 使用悦数图探索连接悦数图数据库。详情参见[连接数据库](https://docs.nebula-graph.com.cn/{{nebula.release}}/nebula-explorer/deploy-connect/ex-ug-connect/)。

## 监控悦数图数据库

在悦数图数据库（阿里云版）中部署悦数运维监控后，可以使用悦数运维监控实时监控悦数图数据库服务的状态。详情参见[悦数运维监控文档](https://docs.nebula-graph.com.cn/{{nebula.release}}/nebula-dashboard-ent/1.what-is-dashboard-ent/)。
