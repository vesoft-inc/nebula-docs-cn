# 创建订阅

在使用 Cloud 之前，用户需要在 Azure 上创建订阅，本文介绍如何在 Azure Marketplace 上创建订阅。

## 订阅流程

1. 进入 [Azure市场](https://portal.azure.com/?l=en.en-us#blade/Microsoft_Azure_Marketplace/GalleryMenuBlade/selectedMenuItemId/home)，在市场的搜索栏搜索 Nebula Graph Cloud。

2. 在 Nebula Graph Cloud 卡片上单击**订阅**，并根据需求选择计划。

  可选计划如下：

  | 计划 | 说明 |
  | - | - |
  | 30-day free trial | 提供 30 天（Solution 实际运行时间）免费试用版服务。选择该计划后，在[配置 Nebula Graph Solution](3.how-to-set-solution.md) 时可以选择 **Free** 版，不能选择其它版本。 |
  | Beta | 付费版服务。选择该计划后，在配置 Nebula Graph Solution 时可以选择 **Enterprise** 版和 **Developer** 版，不能选择 **Free** 版。 |

  ！！！ caution

      - 每个 Azure 账号只能订阅一次 **30-day free trial**，到期后无法再次订阅。
      - **30-day free trial** 不可转为其它计划。

3. 在**订阅 Nebula Graph Cloud** 页面的**基本信息**标签页，完成以下设置。

  - 项目详细信息

    |设置项|说明|
    |:---|:---|
    |订阅|选择订阅。一个 Azure 订阅中的所有资源会在一起计费。|
    |资源组|选择资源组。如果没有选项，单击下拉列表下方的**新建**[创建资源组](https://docs.microsoft.com/zh-cn/azure/azure-resource-manager/management/manage-resource-groups-portal#create-resource-groups)，然后再选择资源组。|

  - SaaS 详情信息

    |设置项|说明|
    |:---|:---|
    |名称|输入 SaaS 订阅的名称。|
    |计划|确认计划信息。单击**更改计划**可变更计划。|
    |计费期限|计划的合同期。当前仅支持**1-月**，不可自定义。|
    |价格 + 付款选项|确认价格和付款选项。|
    |小计|确认预估价格。|
    |定期计费|选择**开**或**关**。处于开启状态时，订阅将在计费期限结束时自动续订。|

4. （可选）在页面底部，单击**下一步：标记**按钮，并根据需要完成[标记](https://docs.microsoft.com/zh-cn/azure/cloud-adoption-framework/decision-guides/resource-tagging/?toc=%2Fazure%2Fazure-resource-manager%2Fmanagement%2Ftoc.json#tagging-decision-guide)设置。

5. 在页面底部，单击**审阅 + 订阅**。

6. 在**审阅 + 订阅**页面，确认订阅信息，并单击底部的**订阅**。

  订阅过程耗时数分钟，请在**订阅进度**页耐心等待。

7. 在**订阅进度**页，单击**立即配置账户**，配置 Nebula Graph Solution。详细信息参见[配置 Solution](3.how-to-set-solution.md)。
