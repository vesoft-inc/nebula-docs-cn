# 配置 Solution

Solution 指运行在 Nebula Graph Cloud 上的 Nebula Graph 数据库。在 Azure 完成订阅后需要于 Cloud 平台上配置 Solution 完成购买，本文介绍如何配置 Solution。

## 配置流程

1. 完成[订阅创建](2.how-to-create-subsciption.md)，并在**订阅进度**页单击**立即配置账户**后，在 **Permissions Requested** 页单击 **Accept** 为 Nebula Graph 授予权限。

2. 在**请选择 Cloud 订阅类型**页，选择需要的 Cloud 服务版本，并单击版本下方的 **Get Started Free** 或 **Create**。

  可选版本如下：

  | 版本 | 说明 |
  | - | - |
  | Free | 为在云上学习与探索 Nebula Graph 设置的 30 天免费试用版。服务为单机架构，规格固定为 DT.C2.M4（2Core），4 GiB RAM，Standard SSD 50 GiB。要选择 **Free** 版，创建订阅时必须选择了 **30-day free trial** 计划。|
  | Enterprise | 企业版。服务为分布式集群架构，规格可按需选择。要选择 **Enterprise** 版，创建订阅时必须选择了 **Beta** 计划。 |
  | Developer | 开发版。服务为单机架构，规格固定为 DT.C2.M4（2Core），4 GiB RAM，Standard SSD 50 GiB。要选择 **Developer** 版，创建订阅时必须选择了 **Beta** 计划。 |

  所有版本的 Solution 都应用 Nebula Graph 企业版内核。

3. 在**实例设置**页的**供应商**区域，选择要创建服务的**地区**。

  !!! caution

        为提升服务性能，建议选择与业务所在地相同或距离最近的区域。

4. 在 **实例**区域，选择查询引擎的类型及数量，存储引擎的类型、磁盘大小及数量。**Free** 版和 **Developer** 版不支持自定义服务规格。

    !!! caution

        为保证服务高可用，建议为 **Enterprise** 版服务至少配置 2 个查询引擎和 3 个存储引擎。

5. 在 **Nebula Graph** 区域，指定一个 Azure 邮箱账户作为 Root 用户。

6. 确认并勾选**服务级别协议**。

7. 单击页面右下角的**下一步**。

8. 在**确认**页，确认服务信息。如果选择的是免费版，还需勾选页面下方的 **Nebula Graph Cloud will stop the solution after 24h of inactivity.**。

  !!! caution

        免费版的 Solution 如果连续 24 小时无活动就会自动停止。

9.  单击页面右下角的**创建**。

至此，用户已经完成了 Solution 的配置。当 Cloud 首页上 Solution 的状态为 **运行中**时，Solution 已创建成功，且 Nebula Graph 服务已开始运行。

## Solution 状态

用户可能会在 Solution 页面上看到如下表描述的状态。

|状态| 状态说明 |
|:---|:---|
| 创建中 | Solution 所需资源已经准备完毕，Solution 自动开始创建，此时 Solution 短暂处于**创建中**状态，可能持续几分钟到十几分钟。|
| 启动中 | 重新启动 Solution，此时 Solution 短暂处于**启动中**状态。 |
| 停止中 | 用户点击停止 Solution 后，此时 Solution 短暂处于**停止中**状态。 |
| 删除中 | 用户点击删除 Solution 后，此时 Solution 短暂处于**删除中**状态。 |
| 运行中 | Solution 创建成功后，会长时间稳定地处于**运行中**状态。 |
| 已停止 | 停止 Solution 后，会长时间稳定地处于**已停止**状态。 |
| 已删除 | 删除 Solution 后，会长时间稳定地处于**已删除**状态。 |
| 创建失败 | Solution 创建失败后，会长时间稳定地处于**创建失败**状态。 |
| 停止失败 | Solution 停止失败后，会长时间稳定地处于**停止失败**状态。 |
| 启动失败 | Solution 开始失败后，会长时间稳定地处于**启动失败**状态。 |


!!! caution

    如果 Solution 长时间处于某个中间状态，刷新页面后仍未改变，说明出现异常，用户需要提交工单处理。

!!! caution

    如果 Solution 处于创建失败、停止失败、启动失败态，用户可以重新执行 **创建、停止、开始** 的操作。 

## 常见问题

Q：免费版的 30 天是怎么计算的？

A：免费版的 30 天从 Solution 创建开始计算。

Q：免费版能不能转为付费版？

A：免费版不支持转为付费版。

Q：为什么我的 Solution 自动停止了？

A：免费版 Solution 会在满足以下任意条件时自动停止：

- 连续 24 小时无用户登录 Cloud。
- 连续 24 小时 Private Link 无流量。
