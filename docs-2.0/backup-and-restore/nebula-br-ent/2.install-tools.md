# 安装备份和恢复工具

备份和恢复 NebulaGraph 企业版数据需要安装 BR 企业版工具和 Agent 工具。本文介绍如何安装 BR 企业版工具和 Agent 工具。

## 安装 BR 企业版工具

BR 企业版工具是一款命令行界面（CLI）工具，可以帮助备份 Nebula Graph 的图空间数据，或者通过备份文件恢复数据。

操作步骤如下：

1. 获取安装包。
   
  !!! enterpriseonly

        通过邮箱（inquiry@vesoft.com）联系销售人员以获取 BR 企业版工具的安装包。
  
  |NebulaGraph 版本|BR-ent 版本|
  |:---|:---|
  |{{nebula.release}}|{{br-ent.release}}|

<!-- 发版前需确认操作步骤及包名
2. 使用`sudo rpm -i <rpm>`命令安装 RPM 包。
  
  例如，安装 BR 企业版需要运行以下命令，默认安装路径为`/usr/local/br-ent/`：

  `sudo rpm -i nebula-br-ent-<version>.x86_64.rpm` -->

在 BR 企业版工具的安装目录下，用户可以通过命令`./br version`查看版本信息。返回以下信息：

```
[br-ent]$ ./br version
Nebula Backup And Restore Utility Tool,V-{{br-ent.release}}
   GitSha: 5e498a4-dirty
   GitRef: main
```

## 安装 Agent 工具

NebulaGraph Agent 工具以二进制形式存在各个机器的安装目录中，通过 RPC 协议对 BR 工具提供服务，负责停止和启动本机中 metad、storaged、graphd 的进程。

在**每台机器**中，进行以下操作：

1. 下载 Agent，建议选择最新版本。

  ```
  wget https://github.com/vesoft-inc/nebula-agent/releases/download/v{{agent.release}}/agent-{{agent.release}}-linux-amd64
  ```
 
  |NebulaGraph 版本|Agent 版本|
  |:---|:---|
  |{{nebula.release}}|{{agent.release}}|

2. 修改 Agent 的名称为`agent`。

  ```
  sudo mv agent-{{agent.release}}-linux-amd64 agent
  ```

3. 授予 Agent 的执行权限。
  
  ```
  sudo chmod +x agent
  ```

4. 执行以下命令启动 Agent：
  
  !!! note

        启动 Agent 前，确保已经启动集群中的 Meta 服务。

  ```
  sudo nohup ./nebula_agent --agent="<agent_node_ip>:8888" --meta="<metad_node_ip>:9559" > nebula_agent.log 2>&1 &
  ```

  - `agent_node_ip`：Agent 所在机器的 IP 地址。
  - `metad_node_ip`：集群中任一 Meta 服务所在机器的 IP 地址。

  例如，

  ```
  sudo nohup ./nebula_agent --agent="192.168.8.129:8888" --meta="192.168.8.129:9559" > nebula_agent.log 2>&1 &
  ```
