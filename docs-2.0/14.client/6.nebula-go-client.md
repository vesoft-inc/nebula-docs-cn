# NebulaGraph Go

[NebulaGraph Go](https://github.com/vesoft-inc/nebula-go/tree/{{go.branch}}) 是一款 Go 语言的客户端，可以连接、管理 NebulaGraph 图数据库。

## 前提条件

已安装 Go，版本为 1.13 及以上。

## 版本对照表

|NebulaGraph 版本|NebulaGraph Go 版本|
|:---|:---|
|{{ nebula.release }}|{{go.release}}|
|2.6.x|2.6.0|
|2.0.x|2.0.0-GA|

## 下载 NebulaGraph Go

- （推荐）如果需要下载指定版本的 NebulaGraph Go，请使用选项`--branch`指定分支。例如安装 v{{ go.release }}发布版本，请执行如下命令：

  ```bash
  $ git clone --branch {{go.branch}} https://github.com/vesoft-inc/nebula-go.git
  ```

- 如果需要安装日常开发版本，请执行如下命令下载`master`分支的源码：

  ```bash
  $ git clone https://github.com/vesoft-inc/nebula-go.git
  ```

## 安装或更新

安装或更新的命令如下：

```bash
$ go get -u -v github.com/vesoft-inc/nebula-go@<tag>
```

`tag`：指定分支。例如`master`或`{{go.branch}}`。

## 核心代码

NebulaGraph GO 客户端提供 connection pool 和 session pool 两种使用方式, 使用 connection pool 需要用户自行管理 session 实例.

### session pool

使用 session pool时，需注意以下限制：

1. 在初始化 session pool 时，NebulaGraph 数据库中必须存在一个图空间。
2. 每个 session pool 对应一个用户和一个图空间，以确保用户的访问控制一致。例如，同一个用户在不同图空间中可能拥有不同的访问权限，如果需要在不同图空间执行查询请求，可能就需要创建多个 session pool。
3. 每次调用`sessinPool.execute()`时，session 会在 session pool 配置中设置的图空间中执行查询请求。
4. 修改密码或删除用户的命令操作不能在 session pool 中执行。

详细示例请参见 [session_pool_example.go](https://github.com/vesoft-inc/nebula-go/blob/{{go.branch}}/session_pool_example/session_pool_example.go)。
